### 🏗️ 架构概览

MCP Feedback Enhanced 采用**单一活跃会话 + 持久化 Web UI**的创新架构，实现了 AI 助手与用户之间的无缝交互体验。

#### 内核特性
- **智能环境检测**: 自动识别 Local/SSH Remote/WSL 环境
- **单一活跃会话**: 替代传统多会话管理，提升性能和用户体验
- **持久化 Web UI**: 支持多次循环调用，无需重复打开浏览器
- **实时双向通信**: WebSocket 实现前后端状态同步
- **智能资源管理**: 自动清理和会话生命周期管理
- **提示词管理系统**: 常用提示词的 CRUD 操作和快速选择
- **自动提交功能**: 倒数计时器和自动回馈提交机制
- **会话管理功能**: 会话历史追踪和统计分析（v2.4.3 重构增强）
- **音效通知系统**: 智能音效提醒和自订音效管理（v2.4.3 添加）
- **智能记忆功能**: 输入框高度记忆和一键拷贝（v2.4.3 添加）
- **多语言支持**: 繁体中文、简体中文、英文动态切换

#### 技术栈
- **后端**: Python 3.11+, FastAPI, FastMCP
- **前端**: HTML5, JavaScript ES6+, WebSocket, Web Audio API（v2.4.3）
- **通信**: WebSocket, HTTP REST API
- **存储**: localStorage（会话历史、音效文档、设置记忆）
- **部署**: uvicorn, 跨平台支持

### 🆕 v2.4.3 版本亮点

#### 🔊 音效通知系统
- **内置音效**: 经典提示音、通知铃声、轻柔钟声
- **自订音效**: 支持 MP3、WAV、OGG 格式上传
- **智能播放**: 会话更新时自动播放通知音效
- **音量控制**: 0-100% 可调节音量
- **浏览器兼容**: 处理自动播放政策限制

#### 📋 会话管理重构
- **页签化设计**: 从侧边栏迁移到独立页签，解决浏览器兼容性问题
- **本地历史存储**: 支持 72 小时可配置保存期限
- **隐私控制**: 三级用户消息记录设置（完整/基本/停用）
- **数据管理**: 导出和清理功能
- **详情查看**: 专门的会话详情弹窗

#### 🧠 智能记忆功能
- **输入框高度记忆**: 自动保存和恢复输入框高度
- **一键拷贝**: 项目路径和会话ID点击拷贝
- **设置持久化**: 用户偏好自动保存
- **国际化支持**: 拷贝提示支持多语言
